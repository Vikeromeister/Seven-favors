## Technical Blueprint

### 1. Card art: `tools/slice_cards.py`
Reference sheets (viewed):
- `art/cards2.png`: clean **2 rows × 7 columns** grid on a white background. Row 0 = women, row 1 = items. Column order (left→right): **chips, burger, spinner, cardigan, sunglasses, ticket, phone** (this is *not* ID order; map by name). This sheet is the source for all 14 faces.
- `art/cards1.png`: 4 rows with mixed column counts. The **bottom-right card of the last row is the card back** (night bridge + moon). It's the only back available, so it's the source for `background_card.png`.

```python
#!/usr/bin/env python3
"""Dev tool: slice art/ reference sheets into docs/assets card images. Requires Pillow."""
from pathlib import Path
from statistics import median
from PIL import Image, ImageOps

ROOT = Path(__file__).resolve().parent.parent
ART, OUT = ROOT / 'art', ROOT / 'docs' / 'assets'
NAMES = ['chips_2pts', 'burger_2pts', 'spinner_2pts', 'cardigan_3pts',
         'sunglasses_3pts', 'ticket_4pts', 'phone_5pts']   # cards2 column order
TARGET_H = 480
INSET = 3          # px trimmed on every side to drop white rounded-corner fringe
WHITE = 232        # channel threshold for "gutter" pixels
GUTTER_FRAC = 0.90 # line is gutter if >= 90% of sampled pixels are white

def _line_is_gutter(img, axis, pos, lo, hi):
    box = (pos, lo, pos + 1, hi) if axis == 'x' else (lo, pos, hi, pos + 1)
    px = list(img.crop(box).getdata())
    white = sum(1 for r, g, b in px if min(r, g, b) >= WHITE)
    return white / max(1, len(px)) >= GUTTER_FRAC

def segments(img, axis, lo=0, hi=None, min_len=80):
    """Runs of non-gutter lines along axis ('x' = columns, 'y' = rows) within band [lo, hi)."""
    w, h = img.size
    hi = hi if hi is not None else (h if axis == 'x' else w)
    n = w if axis == 'x' else h
    runs, start = [], None
    for p in range(n):
        g = _line_is_gutter(img, axis, p, lo, hi)
        if not g and start is None: start = p
        if g and start is not None:
            if p - start >= min_len: runs.append((start, p))
            start = None
    if start is not None and n - start >= min_len: runs.append((start, n))
    return runs

def crop(img, x0, x1, y0, y1):
    return img.crop((x0 + INSET, y0 + INSET, x1 - INSET, y1 - INSET))

def main():
    s2 = Image.open(ART / 'cards2.png').convert('RGB')
    rows = segments(s2, 'y')
    assert len(rows) == 2, f'cards2: expected 2 rows, got {rows}'
    faces = {}
    for r, (y0, y1) in enumerate(rows):
        cols = segments(s2, 'x', y0, y1)
        assert len(cols) == 7, f'cards2 row {r}: expected 7 cols, got {cols}'
        prefix = 'woman_' if r == 0 else 'gift_'
        for c, (x0, x1) in enumerate(cols):
            faces[f'{prefix}{NAMES[c]}.png'] = crop(s2, x0, x1, y0, y1)
    W = int(median(im.width for im in faces.values()))
    H = int(median(im.height for im in faces.values()))
    tw = round(TARGET_H * W / H)
    for name, im in faces.items():
        ImageOps.fit(im, (tw, TARGET_H), Image.LANCZOS).save(OUT / name, optimize=True)

    s1 = Image.open(ART / 'cards1.png').convert('RGB')
    rows1 = segments(s1, 'y')
    y0, y1 = rows1[-1]
    cols1 = segments(s1, 'x', y0, y1)
    x0, x1 = cols1[-1]                       # bottom-right = card back
    back = crop(s1, x0, x1, y0, y1)
    ImageOps.fit(back, (tw, TARGET_H), Image.LANCZOS, centering=(0.5, 0.5)).save(
        OUT / 'background_card.png', optimize=True)
    print(f'--card-ar: {tw / TARGET_H:.4f};  size {tw}x{TARGET_H}')

if __name__ == '__main__':
    main()
```
- If `import PIL` fails, run `python3 -m pip install --user pillow` (dev-only, NOT a runtime dependency).
- Copy the printed decimal into CSS `--card-ar` (expected ≈ `0.50`).
- After slicing, view at least `woman_chips_2pts.png`, `gift_phone_5pts.png` and `background_card.png` to confirm crops are clean.

### 3. `docs/src/fx.js` (new, DOM-only presentation helper)
```js
export const motion = {
  factor: window.matchMedia('(prefers-reduced-motion: reduce)').matches ? 0.01 : 1
};

export function wait(ms) {
  return new Promise((resolve) => setTimeout(resolve, ms * motion.factor));
}

export function rectOf(el) {
  return el.getBoundingClientRect();
}

/**
 * Fly a card clone (in #fx-layer, position:fixed, viewport coords) from one rect to another,
 * optionally flipping it. Front = face image, back = card back.
 * @returns {Promise<HTMLElement>} resolves after landing; the clone is removed unless keep=true.
 */
export function flyCard({ from, to, frontSrc = null, backSrc, startFaceUp, endFaceUp,
                          duration = 550, delay = 0, keep = false }) {
  const layer = document.getElementById('fx-layer');
  const card = document.createElement('div');
  card.className = 'fx-card';
  Object.assign(card.style, {
    left: `${from.left}px`, top: `${from.top}px`,
    width: `${from.width}px`, height: `${from.height}px`
  });
  const inner = document.createElement('div');
  inner.className = 'fx-inner';
  const front = document.createElement('div');
  front.className = 'fx-face fx-front';
  if (frontSrc) front.style.backgroundImage = `url('${frontSrc}')`;
  const back = document.createElement('div');
  back.className = 'fx-face fx-back';
  back.style.backgroundImage = `url('${backSrc}')`;
  inner.append(front, back);
  card.append(inner);
  layer.append(card);

  const dx = to.left - from.left;
  const dy = to.top - from.top;
  const sx = to.width / from.width;
  const sy = to.height / from.height;
  const opts = {
    duration: Math.max(1, duration * motion.factor),
    delay: delay * motion.factor,
    easing: 'cubic-bezier(.2,.7,.2,1)',
    fill: 'forwards'
  };
  const r0 = startFaceUp ? 0 : 180;
  const r1 = endFaceUp ? 0 : 180;
  const move = card.animate([
    { transform: 'translate(0px, 0px) scale(1, 1)' },
    { transform: `translate(${dx / 2}px, ${dy / 2 - 30}px) scale(${((1 + sx) / 2) * 1.08}, ${((1 + sy) / 2) * 1.08})`, offset: 0.5 },
    { transform: `translate(${dx}px, ${dy}px) scale(${sx}, ${sy})` }
  ], opts);
  const flip = inner.animate([
    { transform: `rotateY(${r0}deg)` },
    { transform: `rotateY(${r1}deg)` }
  ], opts);
  return Promise.all([move.finished, flip.finished]).then(() => {
    if (!keep) card.remove();
    return card;
  });
}

export function clearFx() {
  document.getElementById('fx-layer')?.replaceChildren();
}
```

#### 5.5 Turn sequences (all `async`, all take/capture `token = gameToken`, return early if `token !== gameToken` after every `await`)
Common pattern **before** every `Game.perform*` call: `const prevNext = Game.getHand(Game.other(actor));`. After it: `pushHistory(...)` then `await afterCommit(prevNext, token)`.

**Human Secret** (`idx`): `src = handEl(HUMAN, idx)`, `card = hand[idx]`, `src.style.visibility='hidden'`. Fly from `rectOf(src)` to `rectOf(els.playerSecret.firstElementChild)` (the empty slot), `startFaceUp:true, endFaceUp:false`. Then `Game.performSecret(HUMAN, idx)` with history `{player:1, action:'secret', cards:[{card, to:'secret'}]}`.

**Human Tradeoff** (`sel[2]`): hide both sources. Fly each to `rectOf(els.discardPile)`, `true→false`, delay `k*120`. Then `Game.performTradeoff(HUMAN, sel)` with history cards `{card, to:'discard'}`.

**Human Gift** (`sel`):
1. `sel.sort((a,b)=>a-b)`. **Required**: `performGift` maps `chosenOfferIndex` onto ascending hand order.
2. `cards = sel.map(i => hand[i])`.
3. `pendingOffer = {kind:'gift', offerer:HUMAN, cards, revealed:false, interactive:false, chosen:null, hidden:new Set(), resolve:null}`, then `renderOfferTray()`.
4. Hide the sources and fly each to `[data-slot=k]` (`true→true`, delay `k*90`, `keep:true`). Then `revealed=true`, `renderOfferTray()`, and remove the kept clones.
5. `await Fx.wait(700)`, then `choice = AI.chooseAIGiftResponse(aiDifficulty, AI_PLAYER, Game.state, cards)`.
6. `pendingOffer.chosen = choice`, `renderOfferTray()`, `await Fx.wait(450)`.
7. `await distributeOffer(cards.map((_, k) => k === choice ? AI_PLAYER : HUMAN))`.
8. `pendingOffer = null`, then `Game.performGift(HUMAN, sel, choice)` with history cards `{card, to: k===choice?2:1}`.

**Human Competition** (`sel`, **keep selection order**):
- Same flow with `kind:'competition'`. Slots `0,1` = pair 0 and `2,3` = pair 1.
- `aiChoice = AI.chooseAICompetitionResponse(aiDifficulty, AI_PLAYER, Game.state, [cards[0],cards[1]], [cards[2],cards[3]])` returns `1|2`.
- `pendingOffer.chosen = aiChoice - 1`.
- Assign `k => (Math.floor(k/2) === aiChoice-1) ? AI_PLAYER : HUMAN`.
- Then `Game.performCompetition(HUMAN, sel, aiChoice)`.

```js
async function distributeOffer(assign /* receiving player per slot */) {
  const { cards } = pendingOffer;
  const froms = cards.map((_, k) => els.offerTray.querySelector(`[data-slot="${k}"]`).getBoundingClientRect());
  const targets = stackTargetRects(cards.map((card, k) => ({ player: assign[k], card })));
  pendingOffer.hidden = new Set(cards.map((_, k) => k));
  renderOfferTray();
  els.boardRow.classList.remove('offer-active');
  await Promise.all(cards.map((card, k) => Fx.flyCard({ from: froms[k], to: targets[k],
    frontSrc: cardFront(card), backSrc: CARD_BACK, startFaceUp: true, endFaceUp: true, delay: k * 90 })));
}
```

**AI turn** `playAITurn(token)`:
- `decision = AI.chooseAIAction(aiDifficulty, AI_PLAYER, Game.state)`. If it's falsy, set `animating=false`, `render()`, return.
- `secret`: fly `handEl(AI_PLAYER, idx)` (hidden) to the opponent secret slot rect, `false→false`. Then `performSecret`, history `{card:null,to:'secret'}`.
- `tradeoff`: 2 backs to `discardPile`, `false→false`, stagger 120. Then `performTradeoff`, history `{card:null,to:'discard'}`.
- `gift`:
  1. `sel = [...selected].sort((a,b)=>a-b)`, `cards = sel.map(i => aiHand[i])`.
  2. Open the tray (`offerer: AI_PLAYER`) and fly the backs to the slots `false→true` (they flip face up), `keep:true`. Then `revealed=true`, re-render the tray, remove the clones.
  3. `choice = await awaitHumanChoice()`, `pendingOffer.chosen = choice`, `renderOfferTray()`, `await Fx.wait(250)`.
  4. `distributeOffer(k => k===choice ? HUMAN : AI_PLAYER)`, then `pendingOffer=null`, `Game.performGift(AI_PLAYER, sel, choice)`.
- `competition`:
  - Selection order kept. Pairs `[0,1]`, `[2,3]`. Same reveal as gift.
  - `pairIdx = await awaitHumanChoice()` (0|1): the human takes pair `pairIdx`.
  - Assign `k => Math.floor(k/2)===pairIdx ? HUMAN : AI_PLAYER`. Then `Game.performCompetition(AI_PLAYER, sel, pairIdx + 1)`.
- History for AI gift/competition: cards revealed with `to` = receiver.

async function afterCommit(prevNext, token) {
  render();
  if (Game.state.gameOver) {
    await animateReveal(token); if (token !== gameToken) return;
    revealDone = true; render();
    await Fx.wait(700); if (token !== gameToken) return;
    resultReady = true; animating = false; render();
    return;
  }
  const next = Game.state.currentPlayer;
  await animateDraw(next, prevNext, token); if (token !== gameToken) return;
  if (next === AI_PLAYER) { await Fx.wait(500); if (token !== gameToken) return; await playAITurn(token); }
  else { animating = false; render(); }
}

async function animateDraw(player, prevHand, token) {
  const now = Game.getHand(player);
  if (now.length <= prevHand.length) return;          // deck empty → no draw
  const index = findInsertedIndex(prevHand, now);
  hiddenDraw = { player, index }; render();
  const deckRect = els.deckPile.getBoundingClientRect();
  await Fx.flyCard({ from: deckRect, to: handEl(player, index).getBoundingClientRect(),
    frontSrc: cardFront(now[index]), backSrc: CARD_BACK,
    startFaceUp: false, endFaceUp: player === HUMAN, duration: 450 });
  if (token !== gameToken) return;
  hiddenDraw = null; render();
}

async function animateReveal(token) {
  // render() already ran with gameOver && !revealDone → stacks exclude secrets, slots still show backs
  const flights = [HUMAN, AI_PLAYER].map((p, n) => {
    const card = Game.state.secretCard[p];
    if (card === null) return null;

    const from = slotCard.getBoundingClientRect();
    const [to] = stackTargetRects([{ player: p, card }]);

    return Fx.flyCard({ from, to, frontSrc: cardFront(card), backSrc: CARD_BACK,
      startFaceUp: false, endFaceUp: true, duration: 850, delay: n * 300 });

  await Promise.all(flights);
  const aiSecret = history.find((h) => h.player === AI_PLAYER && h.action === 'secret');
  if (aiSecret) { aiSecret.cards[0].card = Game.state.secretCard[AI_PLAYER]; renderHistory(false); }
}

## Edge Cases
1. **Gift index mapping**: `Game.performGift` assigns `chosenOfferIndex` by ascending hand index (`removeCardsFromHand`). Always sort gift indices ascending in the UI (human and AI) before building `cards`. **Don't** sort competition indices, because pair membership depends on order.
2. **Perspective**: always render the human's hand (`HUMAN`) and the AI's backs, never `currentPlayer`. With async flows, `currentPlayer` is 2 for long stretches.
3. **Stale DOM during flights**: calling `render()` mid-flight un-hides sources and moves targets. Only call the documented `render()` / `renderOfferTray()` points. `renderOfferTray` must never rebuild zones.
4. **Fixed overlay vs transformed stage**: `#fx-layer` must live **outside** `#stage`, because a transformed ancestor would break `position: fixed`. Use raw `getBoundingClientRect()` values (already scaled). Stack target sizes multiply CSS px by `currentScale`.
5. **`--card-ar` must be a decimal** (`0.5012`), not `a / b`, because it's read with `parseFloat`.
6. **New game mid-sequence**: `gameToken` check after every `await`, plus `Fx.clearFx()` in `resetUIState`. A dangling `awaitHumanChoice` promise is simply abandoned.
7. **Input lock**: `animating` stays `true` from Confirm until control returns to the human (`afterCommit` human branch) or the result shows. Tray clicks rely on `pendingOffer.interactive`, not `animating`.
8. **Deck exhausted**: `animateDraw` returns early when the hand didn't grow. The deck pile renders an empty slot.
9. **Game-over double counting**: while `gameOver && !revealDone`, stacks subtract the secret card (`displayedStackCount`) so the reveal flight lands on the correct next slot, then `revealDone` re-renders the full counts. Turn 8 is always the AI's, so the game can end inside an AI gift/competition after the human's choice.
10. **Tooltips on disabled actions**: use `aria-disabled` + `.used`, not the `disabled` attribute, so hover tooltips still work. Guard the handlers.
11. **Edge clipping**: right-most action-bar tooltip anchored right. Secret slot and pile tooltips open downward. The history popout opens to the right inside the stage.
12. **Reduced motion**: `Fx.motion.factor = 0.01` makes every flight and wait near-instant without changing control flow.
13. **No scrolling**: `html, body { overflow: hidden }`. All overlays (start screen, result) are inside the stage. Vertical budget: 876 inner = 40 + 120 + 484 + 192 + 16 + 24 gaps. Board needs 2×132 + 180 + 12 = 456 ≤ 484.
14. **Selected card lift** (`-10px`) must not be clipped. No `overflow:hidden` on `.zone`/`.hand-row`.
15. **Global `button:disabled { opacity:.35 }`**: hand cards are `disabled` when not selectable. Override to `opacity:1` so the hand doesn't look faded outside your selection.
